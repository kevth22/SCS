Black White Eagles V11.5

Behoben:
- Vereinsübersicht und Spieltagsverwaltung verwenden denselben state.current-Spieltag.
- Ein offener Spieltag zählt jetzt in der Übersicht als Spieltag.
- Der aktuelle Modus wird auch in der Übersicht angezeigt.
- Offene Spieltage können von Admin und Captain gelöscht werden.
- Abgeschlossene Spieltage können von Admin und Captain gelöscht werden.
- Beim Löschen eines abgeschlossenen Spieltags werden dessen Ranglistenwerte
  soweit anhand der gespeicherten Ergebnisse bzw. Historie möglich zurückgerechnet.
- Alle Löschvorgänge besitzen eine Sicherheitsabfrage.
