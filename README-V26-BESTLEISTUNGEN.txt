V26 – Bestleistungen & Zusatzpunkte

Neu:
- Eigener Menü-Reiter „Bestleistungen“.
- Leistungen werden einzeln pro Spieler und Turnier gespeichert.
- Highscore: 141–180.
- Highfinish: 100–170.
- Shortgame: 9–18 Darts.
- Übersicht für gesamte Saison oder einzelnen Spieltag.
- Klick auf Highscore / Highfinish / Shortgame zeigt die exakten Werte gruppiert, z. B. 3× 180, 4× 171.
- Spielerprofil aus der Rangliste zeigt Foto, Name und alle drei Bestleistungskarten nebeneinander – auch mobil.
- Rangliste enthält Zusatzpunkte und Gesamtpunkte.

Bonuspunkte pro gewertetem Turnier (nur beste Leistung je Kategorie):
Highscore: 141–159 = +1, 160–179 = +2, 180 = +3.
Highfinish: 100–119 = +1, 120–139 = +2, 140+ = +3.
Shortgame: 16–18 = +1, 13–15 = +2, bis 12 = +3.

Alle einzelnen Leistungen bleiben für die Saisonstatistik erhalten. Mehrere gleiche Leistungen werden mit Anzahl angezeigt.
