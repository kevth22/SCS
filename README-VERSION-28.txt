Black White Eagles Version 28 – Anwesenheit im Dashboard

- Die Anwesenheitskarte erscheint nur, wenn der Turnierstatus auf „Anmeldung“ steht.
- Statusänderungen werden im Dashboard live übernommen, ohne Neuladen.
- Angemeldete Spieler können sich selbst als anwesend markieren.
- Ältere Anmeldungen werden zusätzlich über Nickname oder Vor-/Nachname dem Konto zugeordnet.
- Sobald das Turnier auf „Vorbereitung“ oder „Live“ steht, wird die Schaltfläche ausgeblendet.
