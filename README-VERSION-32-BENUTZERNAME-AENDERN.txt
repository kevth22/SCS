VERSION 32 – BENUTZERNAME ÄNDERN

- Admins können in der Kontoverwaltung bei einem Mitglied „Benutzername ändern“ auswählen.
- Der neue Benutzername ist danach der neue Login-Name.
- Das Passwort und die Rolle bleiben erhalten.
- Bestehende Spieltag-Zusagen und Push-Abos werden auf den neuen Benutzernamen umgestellt.
- Die stabile Mitglieds-ID bleibt erhalten, damit Kassenbeiträge nicht verrutschen.
- Das eigene Admin-Konto ist vor einer versehentlichen Umbenennung geschützt.
